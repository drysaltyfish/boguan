# ADR-0016：无人工转写下的 v0.1 验收口径

- **状态**：已接受；**调整 [ADR-0007](0007-v0.1-scope-and-acceptance.md) §2 的 CER 测法**（数值门槛暂缓，其余门槛保留）
- **日期**：2026-11-19
- **相关**：ADR-0007（范围与验收）、ADR-0011（终稿校正）、ADR-0012（实时档位）

## 背景

ADR-0007 §2 把「实时 CER 8–12% / 终稿 CER ≤10%」和「3 段基准语料 + 10 分钟人工转写」定为验收的唯一量尺。项目所有者明确：**不做人工转写**。

没有 ground truth 就无法算 CER。要避免两种坏结局：一是假称「CER 达标」；二是因为缺人工转写就完全不做验收，拿主观感替代客观数据。

## 决策

1. **CER 门槛暂缓（deferred，不是取消）**：在拿到 10 分钟人工转写（或公开中文远场基准集）之前，不报 CER 数字；文档里也不写「CER 达标」。
2. **改为「自动化可测指标 + 单场真实课堂长录音」**，唯一入口是仓库内脚本 `tools/acceptance_report.py`（读设备导出的 `boguan.db`，零依赖）。
3. **指标口径**（v0.1 验收用这套）：

| 维度 | 指标 | v0.1 期望 |
|---|---|---|
| 稳定性 | 单场时长 / 前台服务不中断 / WAV 连续增长 / 无崩溃 | 单场 ≥60 分钟（目标 90），服务全程 `isForeground=true`，WAV 只增不减 |
| 实时可用性 | 字符速率（字/分钟） | 150–250（中文讲课正常带）；明显低于 100 说明转写大面积失败 |
| 实时可用性 | 空段率 / 端点间隔 p90 / >30 s 静默次数 | 空段 <10%；p90 ≤30 s |
| 校正有效性 | 校正改动率、实时↔校正平均相似度、待确认段数 | 改动率 5–50%（过低=没起作用；过高=校正稿偏离）；平均相似度 ≥0.85 |
| 术语命中 | 术语表词在实时稿/校正稿的命中次数（需填术语表） | 校正稿命中 ≥ 实时稿（不应变差） |
| 报告可信度 | 可回听率：条目带 evidence 且能反查到原文时间段的比例（口径见 ADR-0017） | ≥95%（沿用 ADR-0007；旧「要点可定位率」降级为对照） |
| 可读性（可选） | LLM 抽检 1–5 分（20 段） | 平均 ≥4.0 |
| 延迟 | 目前无 app 内打点，用桌面 RTF/首字延迟代理（ADR-0008/0012） | 实时档 1920 ms 实测首字 2.10 s，**超 ADR-0007 的 <2 s**，暂按「接受并待打点复测」处理 |
| 主观可用性 | 项目所有者自评（1–5） | ≥4，且愿意日常使用 |

4. **监控方式**：长录音期间用 `dumpsys activity services` + WAV 字节数轮询（每 2 分钟）留痕，不需要人守着；课后一次性跑验收脚本。

## 后果

**正面**

- 每场真实课都能自动产出可比较的数字，不再依赖「感觉还行」。
- 不引入人工转写的工作量，验收可以每场都跑。
- 稳定性/覆盖/报告定位率这些指标**本来就更接近用户价值**，CER 只解决模型选型。

**负面 / 代价**

- 没有绝对 CER，模型横向比较只能看**相对**（同一份校正稿/术语表作为参照）。
- 「术语命中」依赖用户填术语表；不填时该节为空。
- 延迟依赖 app 内打点，v0.1 只有代理数据。

## 首次真实课堂跑数（2026-11-19，22:51 课堂录音）

见 `docs/acceptance/2026-11-19-class.md`。要点：

- 稳定性：`isForeground=true` 全程采样通过、WAV 单调增长、电量 70→72%、温度 30.7–31.5 °C
- 实时可用性：85 段 / 0 空段 / **209 字/分钟**
- 校正：改动率 37.6%，平均相似度 0.980，待确认 2 段
- 报告：33 条要点、6964 字符、15 条待确认（多数带锚点）

**测量口径的诚实说明**：脚本里的「要点可定位率」是拿要点前 12 个归一化字符去转写里做子串匹配，只能当**改写幅度**的代理；ADR-0007 的原意是「要点能回听到对应片段」，那要求**报告要点自带时间锚点**——当前报告只有「待确认条目」有锚点，要点没有。因此该行在锚点落地前**不能当作 95% 门槛的结论**，只是提示。（锚点已在 [ADR-0017](0017-report-evidence-and-time-anchors.md) 落地；用新口径重测，2026-11-19 这场为 41/46 = 89%，仍未达 95%，见 `docs/acceptance/2026-11-19-class.md`。）

## 复审触发条件

1. 拿到任意一段 ≥10 分钟的人工转写 → 恢复 CER 门槛，并把本 ADR 标记为被取代；
2. app 内加入「音频→首字/上屏时间」打点 → 延迟指标从代理升级为实测。
