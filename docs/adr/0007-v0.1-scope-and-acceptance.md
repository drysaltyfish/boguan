# ADR-0007：v0.1 范围、验收门槛与风险登记

- **状态**：已接受
- **日期**：2026-11-17
- **相关**：全部 ADR

## 1. v0.1 范围

**必须做**

- 录音（开始 / 暂停 / 结束）、四状态状态机
- 实时字幕（前台最新 6–10 行；**屏幕不长亮**；熄屏停渲染、只保录音）
- 端上流式转写（实时稿）
- 会后本地二遍转写（终稿）
- 类型选择（课堂 / 会议）+ 类型化微摘要
- 结构化报告：公共信封 + 类型载荷 → 课堂笔记 / 会议纪要两种渲染
- **锚点回听 + 低置信度实体高亮 + 待确认清单**
- 历史记录列表
- 设置：LLM provider / key、模型下载与管理、音频保留策略、更新检查
- 失败恢复：断网出无摘要版报告；LLM 调用可重放

**明确不做**

| 不做项 | 理由 |
|---|---|
| 说话人分离 | 课堂只需二值判断（二期）；会议完整 diarization 成本高且远场效果无公开数据 |
| 线上会议（系统回环音频） | **Android 平台硬限制**：`AudioPlaybackCapture` 被多数会议 App 禁用；要做必须桌面先行 |
| 云同步 / 账号体系 | 与「数据存本地」冲突 |
| 分享与导出（PDF / DOCX / MD 导出） | 「报告是投影」一旦可导出就会变成用户资产，需要版本与冲突处理 |
| 报告就地编辑 | 同上；用重新渲染代替 |
| 导入已有音频文件 | 需要解码链路（ffmpeg 未装），且非核心价值 |
| 多语言（仅中文） | 缩小验证面 |
| 桌面端 | 平台顺序为 Android 先行 |
| 插件系统 | 大后期；当前只保留 `AsrEngine` / `LlmProvider` / 类型注册表三个内部边界 |

## 2. 验收门槛

| 维度 | 门槛 |
|---|---|
| 实时延迟 | 说话 → 字幕 < **2 s** |
| 实时 CER | **8–12%**（自录课堂基准集） |
| 终稿 CER | **≤10%**（本地二遍） |
| 稳定性 | 连续 **3×90 分钟**无崩溃、无丢音、无断流 |
| 报告可信度 | 抽 20 条要点，**≥95%** 可回听到对应片段 |
| 待办可执行 | 主观评分 **≥70%** |
| 耗电 | 90 分钟前台录音 + 转写 **≤25%** 电量（估计值，实测校准） |

**基准集**：3 段真实课堂录音（10 / 30 / 90 分钟）+ 其中 10 分钟的人工转写 ground truth。**这是验收与模型选型的唯一量尺，缺失则门槛无法执行。**

## 3. 风险登记（明确接受，非遗漏）

| # | 风险 | 处置 |
|---|---|---|
| R1 | 实时模型权重**无 license 声明** | 权重不随项目分发；自用为主；**转公开发布前必须清理** |
| R2 | 4 m 单主讲**真实 CER 无公开基准** | 只信自测；依赖基准语料 |
| R3 | 骁龙 8 Gen 3 的**真机 RTF / 首字延迟无一手数据** | 技术尖峰第一项 |
| R4 | sherpa-onnx **无官方 Maven 包** | AAR 自托管并锁版本 |
| R5 | OpenAI **定价与型号未获官方核验**（本环境 403） | 需有外网权限者复核；模型名全部配置化 |
| R6 | 桌面二期 ASR binding 可能重写 | 已接受；核心与 UI 仍复用 |

## 4. 必办待办

1. **真机技术尖峰**：在一加 12 上跑通 sherpa-onnx 实时管线，实测 RTF、首字延迟、90 分钟耗电与发热。
2. **基准语料**：录制 3 段真实课堂（10 / 30 / 90 分钟）+ 10 分钟人工转写。
3. **OpenAI 官方定价复核**：由有外网权限者核对现役型号与价格（本环境返回 403）。
4. （触发式）**R1 清理**：一旦决定公开发布，先解决 zipformer 权重许可。
